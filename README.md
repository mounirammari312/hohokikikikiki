# Amugar Marketplace & Multi-Tenant Platform 2026

منصة التجارة الإلكترونية وسوق المتاجر المتعددة (Multi-Tenant Marketplace SaaS) الموجهة للسوق الجزائري.

## 🚀 المميزات الرئيسية:
- **واجهة تسوق عصرية 2026 (AliExpress & Temu Style)**:
  - Hero Bento Grid مع سلايدر تفاعلي وعروض صاعقة (Flash Deals) مع عداد تنازلي حقيقي.
  - بطاقة ترحيبية وقسائم شراء للأعضاء الجدد.
  - بطاقات منتجات تفاعلية (Amugar Choice، نسبة الخصم، ومؤشر المبيعات).
- **التوافق مع السوق المحلي الجزائري**:
  - تكامل مع الولايات الـ 58 لحساب رسوم الشحن بدقة (منزل / مكتب).
  - دعم الدفع عند الاستلام (COD) مع نظام فحص وتأكيد الطلبات.
  - دعم شركات التوصيل المحلية (Yalidine, ZR Express, Procolis).
- **لوحات تحكم متكاملة**:
  - لوحة تحكم التاجر (`/admin`) لإدارة المنتجات والطلبات.
  - لوحة الإدارة المركزية (`/super-admin`) لمتابعة أداء المتاجر والمشتركين.
- **تطبيق ويب تقدمي (PWA)**: يدعم التثبيت المباشر على الهواتف والأجهزة الذكية.

## 🛠️ التشغيل والتطوير (Getting Started):

```bash
# تثبيت الحزم
npm install

# تشغيل الخادم المحلي للتطوير
npm run dev

# بناء حزمة الإنتاج
npm run build
```
